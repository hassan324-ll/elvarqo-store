# ELVARQO storefront — Phase 5

Next.js / React / TypeScript public shopping application. See ../README.md and ../docs/PHASE5-SETUP.md for dependencies, configuration and exact run/test instructions. Live catalogue pages use request-time SSR; products, variants, prices and availability come from Laravel. Guest saved pieces use browser storage with current-data refresh.
